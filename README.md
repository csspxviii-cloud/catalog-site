# Каталог товаров из Китая с заказом через WhatsApp

Готовый сайт-каталог: главная, каталог с поиском и фильтрами, категории, карточки товаров и контакты. Кнопка **«Заказать в WhatsApp»** открывает чат с вашим номером и подставляет название товара, артикул, выбранный вариант, цену и ссылку на карточку.

Сайт статический: **нет сервера, базы данных, регистрации и онлайн-оплаты**. Его можно бесплатно разместить на Cloudflare Pages, а ежемесячной платы за конструктор нет.

> **Сейчас сайт работает в демонстрационном режиме.** Все товары, цены, фото и номер WhatsApp — тестовые примеры. Они помечены словом «ДЕМО». Настоящие данные нужно внести по инструкции ниже.

---

## 1. Что где лежит

| Что | Где | Зачем |
|---|---|---|
| `data/site.json` | настройки | название, **номер WhatsApp**, адрес сайта, категории, тексты о доставке |
| `data/products.json` | товары | **весь ассортимент**: названия, цены, артикулы, описания, варианты |
| `images/` | фотографии | сюда кладутся фото товаров |
| `assets/` | оформление | внешний вид (`style.css`) и поведение (`app.js`). Обычно трогать не нужно |
| `public/` | значки | иконка сайта (`favicon.svg`), картинка для соцсетей (`og-image.png`) |
| `build.js` | сборщик | сам создаёт страницы из ваших данных. Запускается автоматически |

Страницы сайта вручную создавать не нужно. Вы меняете только данные, а сайт собирается сам при каждой публикации.

## 2. Первая настройка (сделайте до запуска)

Откройте `data/site.json` и замените значения **внутри кавычек**:

- `siteName` — название вашего магазина.
- `whatsapp` — ваш номер **только цифрами**, с кодом страны, без `+`, пробелов и скобок. Например, для номера +7 701 123 45 67 впишите `77011234567`.
- `phoneDisplay` — тот же номер так, как он будет виден людям: `+7 701 123 45 67`.
- `siteUrl` — адрес вашего сайта **без слэша в конце**. Его вы узнаете после публикации (например, `https://moi-katalog.pages.dev`), тогда вернитесь и впишите.
- `contacts` — город, адрес, часы работы, почта. Пустые поля на сайте не показываются.
- `delivery` и `howToOrder` — тексты о доставке и о том, как заказать. Сейчас там демо-тексты. Напишите только то, что соответствует действительности.
- `categories` — ваши категории. У каждой есть `slug` (латиницей, станет частью адреса), `name` (название) и `description` (подпись).

Когда ввели настоящие данные, поменяйте `"demoMode": true` на `"demoMode": false`.

**Что это даёт:** пока `demoMode` равен `true`, сверху показана жёлтая плашка «Демонстрационная версия», а поисковики не индексируют сайт. Когда станет `false`, плашка пропадёт, а сайт откроется для Google и Яндекса (добавятся `sitemap.xml` и разметка товаров).

## 3. Как добавить товар

Откройте `data/products.json`. Это список товаров в квадратных скобках. Каждый товар находится в фигурных скобках `{ ... }`, и **между товарами стоит запятая**.

Скопируйте любой товар целиком, вставьте после него (не забудьте запятую) и измените значения:

```json
{
  "slug": "naushniki-01",
  "sku": "AR-0101",
  "name": "Беспроводные наушники",
  "category": "elektronika",
  "price": 12900,
  "featured": true,
  "images": ["naushniki-01-1.jpg", "naushniki-01-2.jpg"],
  "description": [
    "Первый абзац описания.",
    "Второй абзац описания."
  ],
  "variants": [
    { "name": "Цвет", "values": ["Чёрный", "Белый"] }
  ],
  "specs": {
    "Материал": "Пластик",
    "Комплектация": "Наушники, кейс, кабель"
  }
}
```

### Что означает каждое поле

| Поле | Обязательно | Пояснение |
|---|---|---|
| `slug` | да | Короткое имя для адреса страницы: латинские буквы, цифры, дефис. Получится `/product/naushniki-01/`. Не должно повторяться |
| `sku` | да | Артикул. Не должен повторяться |
| `name` | да | Название товара |
| `category` | да | `slug` одной из категорий из `data/site.json` |
| `price` | да | Цена в тенге **числом**, без пробелов, кавычек и знака ₸. Правильно: `12900` |
| `images` | да | Список имён файлов из папки `images`. Первая фотография — главная |
| `description` | нет | Описание. Каждый абзац — отдельная строка в кавычках |
| `variants` | нет | Варианты на выбор (цвет, размер). Покупатель должен выбрать их перед заказом. Можно несколько групп |
| `specs` | нет | Характеристики в виде «название»: «значение» |
| `delivery` | нет | Свой текст о доставке для этого товара. Если не указан, берётся общий |
| `featured` | нет | `true` — показать товар на главной в блоке «Избранные» |
| `hidden` | нет | `true` — временно скрыть товар с сайта, не удаляя |

### Частые операции

- **Изменить цену:** найдите товар и поменяйте число в `price`.
- **Убрать товар:** либо удалите весь блок `{ ... }` (и лишнюю запятую), либо добавьте строку `"hidden": true,`.
- **Новая категория:** добавьте блок в `categories` в `data/site.json` и используйте её `slug` в товарах.

> **Важное правило JSON:** после последнего товара и последнего поля внутри блока запятая **не ставится**, а между соседними — ставится. Если ошиблись, сборка остановится и в журнале будет написано, какой товар и что исправить. При этом предыдущая версия сайта остаётся опубликованной.

## 4. Как заменить или добавить фотографии

1. Подготовьте фото: **квадратные, около 1000×1000 пикселей, формат JPG или WebP, размер до 200 КБ**. Так сайт будет быстро открываться на телефонах. Уменьшить и сжать фото бесплатно можно на сайте [squoosh.app](https://squoosh.app).
2. Назовите файл латиницей, без пробелов: `naushniki-01-1.jpg`.
3. Загрузите файл в папку `images`.
4. В `data/products.json` впишите имя файла в поле `images` нужного товара.

Допустимые форматы: `jpg`, `jpeg`, `png`, `webp`, `avif`, `svg`.
Чтобы заменить фото, загрузите новый файл **с другим именем** и укажите его в товаре. Тогда браузеры покупателей не покажут старую картинку из памяти.

Демонстрационные картинки `demo-*.svg` после загрузки своих фото можно удалить.

## 5. Как вносить правки через GitHub (без программ)

Все изменения можно делать прямо на сайте github.com, программы устанавливать не нужно.

**Изменить текст или цену:**
1. Откройте ваш репозиторий на github.com.
2. Нажмите на файл (например, `data/products.json`).
3. Нажмите значок **карандаша** («Edit this file»).
4. Внесите правку.
5. Нажмите зелёную кнопку **Commit changes…**, затем ещё раз **Commit changes**.

**Загрузить фотографии:**
1. Откройте папку `images` в репозитории.
2. Нажмите **Add file → Upload files**.
3. Перетащите фото (или выберите их на устройстве).
4. Нажмите **Commit changes**.

Через 1–2 минуты Cloudflare сам пересоберёт и обновит сайт.
Для массовых правок удобнее компьютер, на телефоне тоже можно, но тесно.

## 6. Публикация на Cloudflare Pages через GitHub

Всё это бесплатно. Нужны два аккаунта: **GitHub** и **Cloudflare**. Банковскую карту ни там, ни там вводить не требуется.

### Шаг 1. Загрузите проект на GitHub

1. Зарегистрируйтесь на [github.com](https://github.com) (кнопка **Sign up**) и подтвердите почту.
2. Нажмите **+** в правом верхнем углу → **New repository**.
3. В поле **Repository name** впишите, например, `katalog`. Выберите **Public** или **Private** (оба варианта работают с Cloudflare). Нажмите **Create repository**.
4. На открывшейся странице нажмите ссылку **uploading an existing file**.
5. Распакуйте архив проекта на устройстве и **перетащите внутрь окна GitHub все файлы и папки** (`data`, `assets`, `images`, `public`, `build.js`, `package.json`, `README.md` и остальные).
6. Внизу нажмите **Commit changes**.

> Папка `dist` в архиве не нужна: она создаётся автоматически. Файлы с точкой в начале имени (`.node-version`, `.gitignore`) тоже загрузите, если они есть в архиве. Если ваша система их скрывает, ничего страшного: сайт соберётся и без них.

### Шаг 2. Подключите репозиторий к Cloudflare Pages

1. Зарегистрируйтесь на [dash.cloudflare.com](https://dash.cloudflare.com) и подтвердите почту.
2. В левом меню откройте **Workers & Pages**.
3. Нажмите **Create application** → вкладка **Pages** → **Connect to Git**.
4. Войдите через GitHub, нажмите **Install & Authorize** и выберите ваш репозиторий `katalog`. Нажмите **Begin setup**.
5. Заполните настройки сборки:

| Поле | Что указать |
|---|---|
| Project name | любое латинское имя, например `moi-katalog` (оно станет частью адреса) |
| Production branch | `main` |
| Framework preset | **None** |
| Build command | `node build.js` |
| Build output directory | `dist` |

6. Нажмите **Save and Deploy**. Через 1–2 минуты сайт соберётся.
7. Cloudflare покажет адрес вида `https://moi-katalog.pages.dev`. Это адрес вашего сайта.

> Названия кнопок в Cloudflare иногда меняются. Если что-то выглядит иначе, ориентируйтесь на смысл: «подключить репозиторий GitHub» → «команда сборки `node build.js`» → «папка результата `dist`».

### Шаг 3. Впишите адрес сайта

Откройте на GitHub `data/site.json`, замените `siteUrl` на настоящий адрес (например, `https://moi-katalog.pages.dev`) и нажмите **Commit changes**. Через минуту сайт обновится, и ссылки в сообщениях WhatsApp будут вести на ваш сайт.

### Шаг 4. Проверьте сайт

- Откройте сайт на телефоне и на компьютере.
- В любой карточке нажмите **«Заказать в WhatsApp»** и убедитесь, что открывается чат с вашим номером, а сообщение содержит название, артикул, цену и ссылку.
- Не отправляйте тестовое сообщение чужим людям: проверьте на своём втором номере или просто посмотрите, как выглядит текст.

### Как узнать, что обновление прошло или не прошло

В Cloudflare откройте **Workers & Pages → ваш проект → Deployments**. Статус **Success** значит, что сайт обновился. Если стоит **Failed**, откройте запись и прочитайте журнал: сборка пишет на русском, в каком файле и в каком товаре ошибка. Исправьте и сохраните файл. Старая версия сайта всё это время остаётся на месте.

## 8. Свой домен (по желанию)

Адрес `.pages.dev` работает бесплатно и навсегда. Собственный домен (например, `moi-magazin.kz`) **покупается отдельно у регистратора**, обычно это платная услуга раз в год. Для запуска он **не обязателен**. Когда решите его подключить, в Cloudflare откройте проект → **Custom domains**, затем не забудьте обновить `siteUrl`.

## 9. Что умеет сайт и чего в нём нет

**Есть:** адаптивная вёрстка (телефоны, планшеты, компьютеры), поиск без учёта регистра и буквы «ё», фильтры по категории и цене, сортировка, галерея фото, выбор вариантов, заказ через WhatsApp, заголовки безопасности (`_headers`), метаданные для поисковиков и соцсетей, иконка сайта, страница 404.

**Нет намеренно:** регистрации, личных кабинетов, корзины и онлайн-оплаты, сервера и базы данных, платных интеграций, отзывов и рейтингов.

## 10. Если нужно проверить сайт у себя на компьютере (необязательно)

Нужен установленный [Node.js](https://nodejs.org) версии 18 и новее. В папке проекта выполните:

```
node build.js
```

Готовый сайт появится в папке `dist`. Для обычной работы это не требуется, так как Cloudflare собирает сайт сам.
